# Project Rules & Customizations

## Git & Confidentiality Rules
- **TUYỆT ĐỐI KHÔNG GIỚI THIỆU HOẶC THỰC HIỆN COMMIT/PUSH FILE `application.properties` (hoặc `backend/src/main/resources/application.properties`) LÊN REMOTE REPOSITORY.**
- Mọi thay đổi trong `application.properties` chỉ được giữ ở môi trường Local cá nhân.
